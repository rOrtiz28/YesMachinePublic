Know the rooftop cat

Sarigüeya

The rooftop cat · Puerto Rico

The cat on the roof is Sarigüeya, a real cat from Puerto Rico. She comes from a town in the center of the island, and what she loves most is watching: the cars going by and everything else that happens on the street below.

In Yes Machine she keeps the same watch from the rooftop. She naps while nothing is going on, sits up when a computer is ready to connect, and gets happy when someone connects.

Tap or click her and she’ll send you a heart.

Add a computer

Use the private address shown in Yes Machine on that computer.

Choose how this computer reaches it. The cable is the fastest; Wi-Fi needs no cable once it’s paired.

  1. On the device, turn on Developer options: in Settings › About, tap Build number seven times.
  2. In Developer options, turn on USB debugging.
  3. Plug the device into this computer, then allow this computer when the device asks.
  1. Put the device on the same Wi-Fi as this computer.
  2. In Developer options, turn on Wireless debugging, then tap Pair device with QR code.
  3. Scan this code with the device.

Wireless debugging turns off when the device restarts or leaves this network. Pair it here again then.

Sign in

Use that computer’s account, the same user name and password you use to log in to it.

This computer has no secure keychain, so the password can’t be remembered.

Disconnected

The connection ended. Check that Yes Machine is still open on that computer, then double-click it to connect again.
