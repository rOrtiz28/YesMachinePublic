Settings

Share when Yes Machine opens

Start sharing as soon as the app opens, so other computers can sign in right away. Turn it off to press Start sharing yourself.

Start Yes Machine when you log in

It opens in the background with only its small icon showing, so your other devices can reach this computer right away.

Share system audio

Send this computer’s sound to the viewer. Change it before you start sharing.

Share the clipboard

Copy on one device and paste on the other while a device is connected, without the Clipboard buttons.

Swap Back and Recents

Android windows show Recents on the left and Back on the right, the way Samsung devices order them.
