Files and Clipboard with Android

When this computer controls an Android device, files and copied text go both ways, as they do with another computer. The device's window gets a Files button and takes files dropped on it; on the device, any app's Share button sends a file back through Yes Machine; and copy and paste just work.

The computer's Settings

The clipboard card from the shared clipboard, with one sentence added: it covers the Android devices this computer controls, with the same switch and the same three ways.

  • To the device: drop files anywhere on the window, or choose them under Files , which is also in the small bar in full screen. They go one after another into the device's Download folder, up to 10 GB each; a name that's already there gets a number, as Android does.
  • From the device: in any app, Share, then Yes Machine. It goes to the connected computer, which asks where to save it, as with files from a viewer. The same works while the tablet is viewing a computer: the file goes to that computer. If no computer is connected, Yes Machine says so.
  • The clipboard: text copied on either side is ready to paste on the other, up to 60 KB, as the computer's Share the clipboard card allows. Nothing shows in the window.
  • Advanced mode carries all of it over the cable or wireless debugging, like the picture. General mode carries it over the app's own connection.
  • One open question in general mode: Android lets only the app in front read the clipboard, so text copied on the device may need a workaround to reach the computer; it has to be tried. Text from the computer always reaches the device, and advanced mode reads the device's clipboard already.
