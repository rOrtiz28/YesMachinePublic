Sharing is on

The other device can switch screens from its tool bar too.

  • Only with two or more screens. On a computer with one screen nothing changes: no Screen button, no Share screen choice.
  • Switching takes about a second. The picture changes to that screen, and the mouse, the keyboard and the viewer’s own pointer on Windows follow it.
  • One choice, remembered on the computer. Whether you switch from the viewer or from the card, the computer remembers it, so the next connection starts on the same screen.
  • The map shows where each screen sits , as the computer arranges them, and its numbers match the rows. Clicking a box in the map switches too.
  • Linux with Wayland: GNOME’s own dialog picks the screen each time sharing starts, so there the menu isn’t offered. All screens at once isn’t part of this.
